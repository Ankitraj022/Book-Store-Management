# 📚 Bookstore Management System

A full-stack web application designed to manage bookstore operations efficiently, including inventory management, search functionality, and admin-controlled operations.

---

## 🚀 Features

- 📖 Add, update, delete, and view books (CRUD operations)
- 🔍 Real-time search and filtering of books
- 🔐 Admin authentication with protected routes
- 📊 Handles 500+ book records efficiently
- 🎯 Responsive and user-friendly UI

---

## 🛠️ Tech Stack

Frontend:
- HTML
- CSS
- JavaScript
- React.js

Backend:
- Node.js
- Express.js

Database:
- MongoDB

## ⚙️ Installation & Setup

1. Clone the repository  
git clone https://github.com/Ankitraj022/Book-Store-Management.git  

2. Navigate to project folder  
cd Book-Store-Management  

3. Install dependencies  
npm install  

4. Run backend  
npm start  

5. Run frontend  
npm run dev
